# Contributing

Thanks for your interest! Open an issue describing the bug or feature before major changes.

1. Fork and branch from `main`.
2. Run `npm install`, `npm run build`, `npm test`, `npm run typecheck`.
3. Add tests for changes to core behavior.
4. Keep tracing opt-in and never collect credentials, request bodies, headers, or response bodies by default.
5. Send a PR explaining the problem, solution, and security implications.

Please do not upload real customer data into issue reports.
